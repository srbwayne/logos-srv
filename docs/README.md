# Logos — Documentation Index

This directory is the canonical documentation entry point for the modernization of Logos.

## Mission

Evolve the existing Logos codebase incrementally into an independent deterministic progression engine/service. LifeOS is expected to become its first client, while identity, authentication and personal facts remain outside the Logos core.

## Status labels

- **OBSERVED** — confirmed in the current repository.
- **DECIDED** — explicitly accepted migration direction.
- **PROPOSED** — design hypothesis requiring approval before implementation.
- **UNKNOWN** — requires investigation; agents must not invent an answer.

## Governing principle

> Preserve behavior first. Improve boundaries second. Extract modules only after boundaries are proven.
