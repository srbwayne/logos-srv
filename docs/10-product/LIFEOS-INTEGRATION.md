# LifeOS Integration — Product View

LifeOS is the first intended consumer of Logos.

The initial integration must be reversible and should use **shadow mode**: LifeOS keeps its current authoritative behavior while the same eligible fact is evaluated by Logos and the results are compared. Logos becomes authoritative only after explicit acceptance criteria are met.

A good first vertical is a small, deterministic LifeOS event such as book completion, provided the LifeOS contract is inspected before implementation.

No LifeOS schema or API shape is assumed by this document.
