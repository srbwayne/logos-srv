# Definition of Done

A modernization slice is done only when:

- the intended behavior is explicit;
- affected behavior is covered by tests;
- targeted tests pass;
- the applicable broader suite passes or failures are documented as pre-existing;
- no unrelated source/migration changes were introduced;
- architecture/docs are updated when the slice changes a documented boundary;
- migration compatibility is preserved;
- the final report identifies remaining debt instead of hiding it.
